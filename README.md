# ⚡ RAW. — Real Conversations. No Filters.

**RAW.** is a social conversation experience designed around honest questions, group interaction and playful challenges.

🌐 **Live Demo:** [Try RAW.](https://raw-app-bice.vercel.app)

## ✨ Features

- Deep End and Unfiltered conversation modes
- Experimental games through The Lab
- Swipe-based interaction
- Haptic feedback
- Local settings persistence
- Mobile-first responsive interface
- Animated card transitions
- Content and language settings

## 🛠️ Tech Stack

- React
- Tailwind CSS
- Framer Motion
- Lucide React
- Web Haptics API
- Vite / Vercel

## 🚀 Run locally

```bash
git clone https://github.com/16alves02/raw-app.git
cd raw-app
npm install
npm run dev
```
