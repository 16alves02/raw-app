# ⚡ RAW. — Real Conversations. No Filters.

[](https://reactjs.org/)
[](https://tailwindcss.com/)
[](https://www.framer.com/motion/)
[](https://vercel.com/)

A **RAW.** não é um jogo de cartas comum; é um desbloqueador de realidade. Numa era de filtros digitais e conversas superficiais, a RAW. propõe o oposto: a verdade nua e crua através de dinâmicas de grupo e conexão profunda.

-----

## 🌐 Live Demo

[Experimenta aqui a RAW.](https://raw-app-bice.vercel.app) 🔥

-----

## 💡 Features

  - 🃏 **Três Modos de Jogo:** De vulnerabilidade emocional (**Deep End**) a caos social (**Unfiltered**).
  - 🧪 **The Lab:** Modos experimentais com lógica dinâmica (*O Impostor*, *Palavras Proibidas*).
  - 🖐️ **Experiência Tátil:** Sistema de gestos (*Swipe*) e feedback haptics integrado.
  - ⚙️ **Painel de Configurações:** Gestão de animações, filtros de conteúdo e idioma.
  - 💾 **Persistência Local:** Definições guardadas automaticamente via `localStorage`.
  - 📱 **Mobile-First Design:** Interface brutalista otimizada para utilização em contexto social.
  - 🎭 **Animações Fluídas:** Transições de cartas suaves alimentadas por Framer Motion.

-----

## 🛠️ Tech Stack

  - **React.js** – Arquitetura de componentes e Hooks.
  - **Tailwind CSS** – Design brutalista e responsivo de alto contraste.
  - **Framer Motion** – Orquestração de animações e gestos físicos.
  - **Lucide React** – Iconografia minimalista.
  - **Haptic API** – Feedback vibratório para maior imersão.

-----

## 🎨 Design System

A identidade visual é focada no essencial, utilizando uma estética **premium-dark**.

| Elemento | Cor | Hex |
| :--- | :--- | :--- |
| Background | Deep Onyx | `#0D0D0D` |
| Primary Accent | Electric Cyan | `#00F0FF` |
| Danger/Spicy | Vivid Red | `#FF3E3E` |
| Text/Cards | Raw Bone | `#F2F2F2` |

## 📦 Instalação

1.  Clone o repositório:
    ```bash
    git clone https://github.com/16alves02/raw-app.git
    ```
2.  Instale as dependências:
    ```bash
    npm install
    ```
3.  Inicie o servidor de desenvolvimento:
    ```bash
    npm start
    ```

-----

## 🧱 Estrutura do Projeto

```text
src/
 ├── components/    # Componentes reutilizáveis (Card, Layout, Header)
 ├── data/          # Decks e questões organizados por modo (.json)
 ├── pages/         # Views principais (Home, Game, Settings)
 ├── styles/        # Configurações globais de CSS e Tailwind
 └── utils/         # Helpers (Feedback tátil, lógica de jogo)
```

-----

## ⚡ Como Jogar

1.  Seleciona um dos três arquétipos (**Deep End**, **Unfiltered** ou **Lab**).
2.  Escolhe um deck específico para o contexto atual.
3.  **Desliza (Swipe)** para a esquerda para passar à próxima pergunta.
4.  Responde com honestidade. Sem filtros.
